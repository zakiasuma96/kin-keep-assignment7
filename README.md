## Project Description

This is a short web project. Where a user can see his friend. The user can call, text, and video call his friend. And check the whole list of calls, texts, and videos. This project has a pie chart where user can check the data based on his call, text and videos.

## Technologies
1. React.JS
2. JSON
3. React-Toastify
4. Tailwind CSS & DaisyUI
5. Recharts 

## Feature

2. Text
3. Video
